# Baseline model comparisons

This folder preserves exploratory baseline work across Gemma model versions.

- `01_gemma4_baseline.ipynb` reproduces the held-out IAT baseline for `google/gemma-4-E4B-it`.
- `02_gemma3_vs_gemma4_baseline.ipynb` compares Gemma-3 and Gemma-4 baseline metrics from their 50×12 result CSVs.

These comparisons are **secondary / exploratory**. The current project fine-tuning scope remains `google/gemma-3-12b-it`, following the research team's current direction.

The public notebooks contain code only and intentionally omit embedded face images, authentication tokens, checkpoints, and model weights.
