## Slide citation format

Use a small source line beneath each figure/table, for example:

`Source: notebooks/06_gemma3_visbias_base_vs_v2.ipynb; results/metrics/visbias_base_vs_v2_summary.csv`

For the summary slide:

`Source: docs/external_benchmarks.md; results/metrics/cross_benchmark_summary.csv`

Keep the same plotting grammar across benchmark figures where the metric allows: wide figure, Base in blue, V2 in orange, consistent labeling.
